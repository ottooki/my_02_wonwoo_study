# 원우 공부

원우가 일주일(월~일) 공부 계획을 스스로 세우고, 알림을 받아 공부를 시작·완료하고, 공부한 내용을 기록하는 안드로이드 앱입니다.

## 기능

- **스케줄 입력**: 과목, 요일(여러 개), 시작·종료 시간, 반복 기간(시작일~종료일), 공부 목표, 메모, 알림 켜기/끄기. 기간 안의 선택한 요일마다 자동으로 반복됩니다. 시간이 겹치면 알려줍니다.
- **주간 시간표**: 월~일 시간표에 과목 색으로 표시하고 상태(⏳ 예정, ▶️ 공부중, ✅ 완료, ❌ 못함)를 보여줍니다. ◀ ▶ 버튼이나 좌우로 밀어서 주 단위로 이동하고, 가운데 날짜를 누르면 이번 주로 돌아옵니다. 빈 칸을 누르면 그 요일·시간으로 바로 스케줄을 추가합니다.
- **오늘**: 오늘 공부 목록과 [공부 시작] 버튼, 공부 중이면 경과 시간과 [공부 완료] 버튼.
- **공부 기록**: 주간 완료 수, 완료율, 실제 공부 시간(계획 대비), 과목별 공부 시간, 요일별 기록. 누르면 세부 내역(계획 시간, 실제 시작·완료 시각, 공부한 내용, 스스로 평가)을 볼 수 있습니다.
- **완료 기록**: 공부한 시간(자동 입력, 고칠 수 있음), 공부한 내용, 스스로 평가(😥 어려웠어 / 🙂 보통 / 😄 잘했어). 못한 날은 이유(학원, 숙제, 아팠어 등)를 남깁니다.
- **설정**: 과목 추가·삭제(색 선택), 알림 권한 확인, 테스트 알림, 전체 반복 스케줄 목록.

## 알림 규칙

| 알림 | 시각 | 보내지 않는 경우 |
|---|---|---|
| 시작 알림 | 시작 10분 전 | 그 전에 [공부 시작]을 이미 눌렀을 때 |
| 종료 알림 | 종료 시각 | 그 전에 [공부 완료]나 [못했어]를 이미 기록했을 때 |

- 알림을 누르면 그 일정의 화면이 바로 열립니다.
- 앞으로 14일치 알림을 미리 예약하고, 앱을 열거나 기록이 바뀔 때마다 다시 예약합니다. 2주 넘게 앱을 열지 않으면 그 뒤 알림은 오지 않습니다.
- 데이터는 휴대폰 안에만 저장됩니다 (인터넷 필요 없음). 앱을 지우면 기록도 지워집니다.

## 원우 폰에 설치하기 (APK)

1. GitHub 저장소의 **Actions** 탭 → **Android APK** → 가장 최근 성공한 실행을 엽니다.
2. 아래쪽 **Artifacts**의 `wonwoo-study-apk`를 내려받아 압축을 풀면 `app-release.apk`가 나옵니다.
3. APK를 원우 폰으로 옮겨(카카오톡 나에게 보내기, 구글 드라이브, USB 등) 엽니다.
4. "출처를 알 수 없는 앱" 설치 허용을 묻으면 허용합니다.
5. 처음 실행하면 **알림 허용**을 눌러주세요. 설정 탭에서 "정확한 시간 알림 켜기"가 보이면 그것도 켜야 알림이 제시간에 옵니다.
6. 삼성폰은 설정 → 배터리 → 백그라운드 사용 제한에서 이 앱을 "제한 없음"으로 두면 알림이 더 안정적입니다.

새 버전을 설치할 때도 같은 방법으로 덮어 설치하면 기록이 유지됩니다.

## 개발

```bash
npm install
npm test          # 반복·알림 로직 테스트
npm run typecheck
npx expo start    # 개발 서버
npm run web       # 브라우저 미리보기 (알림은 동작하지 않음)
```

알림·날짜 선택 등 네이티브 기능은 Expo Go 대신 실제 빌드(APK)나 `npx expo run:android`로 확인해야 합니다.

### 구조

- `App.tsx`: 하단 탭(시간표 / 오늘 / 공부 기록 / 설정)과 세부·편집 화면 모달
- `src/store.tsx`: 데이터 저장(AsyncStorage)과 변경 시 알림 재예약
- `src/lib/schedule.ts`: 기간·요일 반복 계산, 시간 겹침 확인
- `src/lib/notifyPlan.ts`: 어떤 알림을 언제 보낼지 계산 (테스트 대상)
- `src/lib/notifications.ts`: expo-notifications 예약·권한
- `src/screens/`: 각 화면
